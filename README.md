# Trisian website

Static site, no build step. Open `site/index.html` in a browser, or serve the `site/` folder with any static host.

- `site/index.html`: homepage
- `site/css/styles.css`: palette tokens at the top (locked palette, do not add colors)
- `site/js/main.js`: scroll-driven diagrams (Empty Room, Industry-Bound, Zero Markup) and the form
- `site/assets/`: subsetted fonts (Archivo, Google Sans), logo, placeholder photography

Open items: tier names (Core/Advanced/Enterprise are placeholders), testimonial quotes, assessment form is not wired to email/CRM yet.
